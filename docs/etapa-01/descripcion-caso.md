# Descripción del Caso de Estudio — SkyTech Store

## Introducción al Rubro
El presente proyecto contempla el desarrollo del modelo de base de datos relacional para **SkyTech Store**, una tienda de comercio electrónico (*e-commerce*) dedicada a la comercialización de componentes de tecnología, hardware e insumos informáticos[cite: 5].

## Problemática y Propósito
El sistema está diseñado para administrar el ciclo operativo completo de ventas en línea[cite: 5]. Permite gestionar el catálogo de productos organizados por categorías, administrar los datos de los clientes, mantener la persistencia interactiva del carrito de compras activo y procesar la conversión de carritos a órdenes de venta[cite: 5]. Asimismo, garantiza el registro de los métodos de pago utilizados y preserva un historial inalterable de transacciones y precios para auditorías futuras[cite: 5].
